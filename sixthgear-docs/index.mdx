## System summary

SixthGear is a Next.js 15 App Router storefront backed by Shopify. Shopify owns catalog, cart, customer, order, and hosted checkout data.

Sanity supplies structured website content through an embedded Studio at `/studio`. Active Strapi imports remain, so treat the CMS layer as a Sanity and Strapi hybrid until migration is verified complete.

Vercel is the repository-supported hosting platform. Upstash Redis and Next.js cache tags reduce repeated API work. GitHub Actions runs Playwright smoke tests.
