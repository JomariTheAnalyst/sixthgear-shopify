Shopify is the commerce system of record. Use Shopify Admin for products, variants, inventory, collections, tags, metafield values, discounts, customers, orders, checkout settings, and installed apps.

The SixthGear storefront reads Shopify through the Storefront GraphQL API. It sends customers to Shopify's hosted checkout instead of processing payment inside Next.js.

## What the storefront expects

| Shopify data | Storefront use |
| --- | --- |
| Product title, description, media, price and vendor | Product cards, product pages and search |
| Variants and availability | Option selection, price changes and stock state |
| Collections | Store navigation, collection pages and brand filters |
| Tags and product type | Filtering and related-product ranking |
| Product metafields | Specifications, sizing, shipping, video and review details |
| Collection metafields | Landing-page copy, fitment, guides, related collections and FAQs |
| Cart | Line items and Shopify-generated checkout URL |

## Where to make a change

- Change a sellable item in **Products**.
- Change a category or brand grouping in **Products** > **Collections**.
- Change structured product details in the product's metafield fields.
- Change homepage or editorial content in [Sanity CMS](/sanity/overview), unless the content still comes from Strapi.
- Change storefront behavior in the source repository, not in Shopify theme code.

<Warning>
SixthGear is not a Liquid theme. Editing a Shopify theme does not update this Next.js storefront unless a separate integration is confirmed.
</Warning>
